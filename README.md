# Organizador de Declaracao de Imposto de Renda

Ferramenta desenvolvida no Microsoft Excel para reunir, organizar e validar informacoes necessarias a preparacao da declaracao anual de imposto de renda.

## Objetivo

Centralizar os dados do contribuinte em um unico arquivo, facilitando o acompanhamento de rendimentos, bens, despesas dedutiveis e documentos de apoio. A organizacao por categorias reduz esquecimentos e torna a conferencia das informacoes mais pratica.

## Arquivo principal

- [Organizador de Declaracao de Imposto de Renda](./ORGANIZADOR_DE_DECLARACAO_DE_IMPOSTO_DE_RENDA.xlsx)

Abra o arquivo com o Microsoft Excel para utilizar os menus, campos de preenchimento, validacoes e links rapidos.

## Funcionalidades

- Menu de navegacao entre as areas da planilha.
- Registro organizado de rendimentos tributaveis e isentos.
- Controle de bens, direitos e dividas.
- Reuniao de despesas e pagamentos relevantes.
- Campos para identificar documentos pendentes e observacoes.
- Listas de selecao e validacoes para reduzir erros de preenchimento.
- Links rapidos para facilitar o acesso as secoes e referencias oficiais.
- Estrutura preparada para revisao antes do envio da declaracao.

## Como utilizar

1. Faca uma copia do arquivo antes de iniciar o preenchimento.
2. Comece pelo menu inicial e avance pelas secoes na ordem indicada.
3. Preencha os dados usando os formatos e opcoes disponiveis nas celulas.
4. Marque documentos pendentes e registre observacoes quando necessario.
5. Revise os totais e confira os dados com os documentos originais.
6. Consulte um profissional habilitado em caso de duvida tributaria.

Esta ferramenta auxilia na organizacao. Ela nao substitui a conferencia das regras vigentes nem a orientacao de um contador.
